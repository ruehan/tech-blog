포털 내부 월드 GLB — v27

기존 Blender v26의 월드를 분리한 파일입니다. 방에서 해당 포털을 선택했을 때 필요한 파일만 불러오는 구성을 위한 준비물이며, 웹 코드는 포함하지 않았습니다.

파일
- computer-desktop.glb: 폴더·사진·코드 편집기·음악 플레이어가 있는 컴퓨터 내부. DesktopAmbient는 약 10초 반복, DesktopFolderOpen은 2.5초 동안 폴더가 열리는 동작입니다. 폴더 닫기는 추후 같은 클립을 역재생할 수 있습니다.
- apex-circuit.glb: 고저차가 있는 서킷과 출발 대기 중인 차량 5대. 운전할 차량은 포함하지 않아 별도 파일로 불러올 수 있습니다.
- formula-car-animated.glb: 상세 콕핏이 있는 운전자 차량. WheelSpin(1초), FrontSteer(3초), SteeringWheel(3초) 클립이 있습니다. FrontSteer와 SteeringWheel은 함께 재생합니다.
- development-atelier-optional.glb: 이전 개발 아틀리에를 보존한 선택용 파일. 새 컴퓨터 월드를 사용할 때는 불러오지 않아도 됩니다. AtelierProjects, AtelierLab, AtelierNotes는 각각 약 9초입니다.

배치와 카메라
- GLB는 미터 단위, +Y가 위입니다. 각 월드의 루트는 원점으로 옮겼습니다. 원래 방 옆에 배치하기 위한 큰 좌표는 제거했습니다.
- 서킷과 운전자 차량을 같은 부모에 둔 뒤, 차량 위치를 GLB 좌표 (-3, 0, 0), 회전 (0, 0, 0)으로 설정하면 기존 출발 위치가 됩니다.
- 출발 콕핏 카메라는 서킷 기준 GLB 위치 (-3, 0.85, -0.10)에서 -Z 방향을 바라봅니다. 수직 시야각은 약 49.55도입니다.
- 컴퓨터 월드의 정면 카메라는 GLB 위치 (0, 2.80, 8.00)에서 -Z 방향을 바라봅니다. 수직 시야각은 약 35.05도입니다.
- 원본 카메라 행렬·렌즈·조명 설정은 worlds-manifest.json의 source_cameras, source_lights에 있습니다. 이 행렬은 Blender 좌표(+Z 위)입니다. 위치를 GLB 좌표로 바꾸는 규칙은 (x, y, z) → (x, z, -y)입니다.
- GLB 자체에는 카메라·조명을 넣지 않았습니다. 웹의 카메라와 환경광·직접광은 별도로 연결합니다.

재질과 최적화
- 사진과 우드 텍스처는 GLB 안에 포함했습니다. PBR 색상·거칠기·금속성·발광을 보존했습니다.
- 고정된 부품은 같은 상호작용 부모 아래에서 합쳤습니다. 움직이는 축, 폴더·창·차량의 이름과 계층은 유지했습니다.
- 하늘 구체, 중복된 메인 룸, 프리뷰 카메라는 제외했습니다. 웹 배경색/환경은 나중에 설정합니다.
- 아스팔트·카본·고무의 Blender 절차형 미세 요철은 제외했습니다. 해당 재질의 기본 색상과 PBR 성질은 유지됩니다. 아주 가까운 확대에서 이 미세 요철이 필요하면 텍스처로 추가 베이크할 수 있습니다.
- 서킷 출발 신호등의 발광 변화는 glTF의 일반 변형 클립으로 내보내지 않았습니다. 조절할 재질·오브젝트 이름과 원본 키프레임을 manifest의 material_animations_for_later_runtime_connection에 남겼습니다.
- Blender의 렌더 결과와 웹 화면이 자동으로 같아지는 파일은 아닙니다. 이 폴더는 조명을 나중에 계산하는 일반 PBR GLB입니다.
- 압축 전 표준 GLB입니다. 고해상도 메시가 남아 있으므로 모바일 목표 성능은 실제 웹 연결 후 측정하며, 필요하면 더 낮은 단계의 모델·Draco/Meshopt 압축을 추가합니다.

검증과 미리보기
- worlds-manifest.json: 파일 크기, 치수, 이름, 클립, 소스 설정과 제한 사항.
- worlds-validation.json: Blender로 다시 불러와 원본 애니메이션의 주요 프레임과 비교한 결과.
- *-preview.png: 실제 내보낸 GLB를 다시 불러와 만든 확인용 이미지입니다. 확인용 조명·카메라는 이미지에만 사용했으며 GLB 안에는 없습니다.
- Blender 원본 v26은 변경하지 않았습니다.
