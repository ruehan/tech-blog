# Hangyu’s room

React 19 + React Three Fiber 9 + Drei + TypeScript + Vite로 만든 3D 공간 탐색 웹입니다.

## 실행

```sh
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다. `npm run build`는 타입 검사와 프로덕션 빌드, `npm run preview`는 빌드 미리보기, `npm test`는 에셋 연결과 애니메이션 데이터 검증을 실행합니다.

`npm run test:browser`는 설치된 Chrome으로 월드 전환·조명·모바일·로딩 실패 복구를 검증합니다. 다른 환경에서는 `npx playwright install chromium` 후 `PLAYWRIGHT_CHANNEL=chromium npm run test:browser`를 사용합니다.

## 구현 범위

- 메인 방: 오프닝, 책·베이스 클릭 연출, 개별 호버, 모니터·시뮬레이터 포털 접근, 조명 전환.
- 컴퓨터: 데스크톱 애니메이션, Projects 폴더 열기·닫기.
- 서킷: 운전석 1인칭 시점으로 진입하며, 서킷 전체·차량 근접 시점으로 전환 가능. 시점 초기화는 운전석으로 복귀.
- 공통: 아이콘 기반 월드 메뉴와 조작 버튼, 방으로 복귀, 일시정지, 시점 초기화, 로딩·오류 상태, 모바일 레이아웃. 운전석 외 시점에서는 드래그 회전과 확대 지원.
- 동작 줄이기 설정을 사용하면 애니메이션을 기본 일시정지합니다. Esc는 연출 취소 또는 방으로 복귀합니다.
- 블로그: 원본 Book_Click 클립의 접근·펼치기까지만 재생한 후 5초 지점에서 큰 책 형태의 읽기 화면을 엽니다. 읽는 동안 3D 렌더링을 멈추며, 포스트 창을 닫으면 같은 자세의 323/24초(약 13.46초) 지점부터 곧바로 책을 덮고 방으로 복귀합니다. 중간 페이지 확대·축소 구간은 생략합니다. 왼쪽에는 태그 필터와 글 목록, 오른쪽에는 선택한 글을 함께 표시합니다. 글을 바꾸면 오른쪽 페이지만 책등을 축으로 살짝 넘어가며, 이전 글은 반대 방향으로 전환합니다. 목차, 관련 글, 링크 복사와 글별 스크롤 복원을 지원합니다. 모바일은 목록과 본문을 전환하고, 동작 줄이기 설정에서는 페이지 전환 애니메이션을 생략합니다.
- 프로젝트: 컴퓨터의 DesktopFolderOpen 클립이 끝나면 목록을 표시합니다. 열리는 도중 닫으면 목록을 열지 않습니다. 프로젝트 상세 페이지에는 현재 블로그 프로젝트 1개를 등록했습니다.
- 책·베이스·모니터·심레이싱의 클릭 연출은 현재 카메라 위치·회전·배율과 호버 자세에서 원본 첫 프레임까지 0.65초 동안 부드럽게 정렬한 뒤 시작합니다. 방으로 복귀하는 책·음악 연출과 최초 진입 연출도 마지막 프레임에서 기본 방의 카메라·자세·조명으로 0.65초 동안 전환한 뒤 조작을 다시 활성화합니다. 전환 중에도 일시정지·건너뛰기·Esc 취소가 가능합니다.
- 책의 진입 연출은 건너뛰어 바로 읽거나 Esc로 취소할 수 있습니다. 동작 줄이기 또는 일시정지 상태에서도 콘텐츠에 바로 접근할 수 있습니다.

## 글과 프로젝트

- `/posts`: 글 목록. `?tag=React`처럼 태그를 주소에 저장합니다.
- `/posts/building-a-room-on-the-web`: 글 본문. 주소로 직접 들어오면 3D 장면을 불러오지 않습니다.
- `/projects`: 프로젝트 목록.
- `/projects/hangyu-room`: 이 블로그의 프로젝트 소개와 관련 작업 기록.

`src/content.ts`에서 글 메타데이터와 본문 섹션을 편집합니다. 문단·목록·코드·안내문 블록을 지원하며, 초기 글 3개는 현재 구현을 설명하는 초안입니다. `src/Blog.tsx`가 목록과 읽기 화면을, `src/navigation.tsx`가 링크 및 브라우저 뒤로가기·앞으로가기를 담당합니다.

현재는 클라이언트 렌더링 방식입니다. 배포할 때 `/posts/*`, `/projects/*` 요청을 `index.html`로 연결하는 호스팅 설정이 필요합니다. 검색 및 소셜 미리보기용 정적 본문·메타데이터 생성은 별도 후속 작업입니다. 개발 서버에서는 본문 주소 새로고침을 바로 지원합니다.

## 에셋과 구조

`blog-room-v27/`이 원본입니다. `scripts/prepare-assets.mjs`가 실행·빌드 전에 필요한 GLB와 JSON만 `public/assets/`로 복사합니다. Blender 파일과 검증 자료, 선택용 아틀리에, 정적 베이크 비교본은 웹 번들에 포함하지 않습니다. 컴퓨터와 서킷은 해당 월드에 진입할 때 불러옵니다.

`src/Room.tsx`는 GLB 클립과 24fps sidecar 데이터를 같은 시간으로 재생합니다. 오프닝의 첫 프레임을 표시 전에 적용하고, 마지막 프레임에서 기본 화면 배율로 부드럽게 연결합니다. 각 오브젝트의 Idle/Hover는 짧게 혼합해 전환하며, 하위 메시 사이의 포인터 이동으로 호버가 재시작되지 않도록 처리합니다. 클릭 연출 중에는 오브젝트 Idle과 카메라 조작을 멈춥니다. 조명은 별도 상태로 유지합니다. 원본 GLB 캐시를 변경하지 않도록 각 월드는 계층과 재질을 복제합니다.

`src/WorldScene.tsx`는 카메라, 조명과 월드 렌더링을, `src/App.tsx`는 내비게이션과 접근 가능한 UI를 담당합니다.

현재는 공간 탐색과 블로그 읽기 프로토타입입니다. 오디오, 차량 주행·물리, 서버·인증, 관리용 편집기는 포함하지 않습니다. PBR 조명은 웹에 맞춰 근사했으며 Blender 렌더와 픽셀 단위로 동일하지 않습니다. 원본 GLB의 메시·텍스처 압축과 모바일 GPU 성능 최적화는 후속 작업입니다.
